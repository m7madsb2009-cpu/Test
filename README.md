# تطبيق عداد (أندرويد)

تطبيق بسيط: زر +1 وزر تصفير، والعدد ينحفظ حتى لو سكرت التطبيق.

## كيف تطلع ملف الـ APK (مجاناً، بدون برامج على الكمبيوتر)

1. سوّ حساب على https://github.com (مجاني).
2. اضغط **New repository**، سمّه `counter` واتركه Public أو Private.
3. اضغط **uploading an existing file**، وارفع **كل محتويات** هذا المجلد (بعد فك الضغط).
   - مهم: لازم المجلد المخفي `.github` يندفع معهم. لو الرفع من المتصفح ما رفعه، استخدم تطبيق GitHub Desktop أو ارفع الملف `build-apk.yml` يدوياً داخل المسار `.github/workflows/`.
4. اضغط **Commit changes**.
5. روح تبويب **Actions** وانتظر دقيقتين إلى خمس لين يصير الدائرة خضراء ✅.
6. افتح آخر عملية تشغيل، ونزّل من قسم **Artifacts** الملف `counter-apk` (يجي مضغوط، فكّه وتلقى `app-debug.apk`).

لو طلعت علامة ❌، افتحها وانسخ الخطأ وارسله لي.

## التثبيت على Galaxy A07

1. انقل الـ APK للجوال (ميديا فاير، تيليجرام، كيبل، أي طريقة).
2. **الإعدادات ← الأمان والخصوصية ← Auto Blocker** وأطفئه (سامسونج يمنع التثبيت من خارج المتجر وهو شغال).
3. افتح الملف من تطبيق **ملفاتي**، واسمح للتثبيت من هذا المصدر لما يسأل.
4. اضغط **تثبيت**. لو طلع تحذير Play Protect اختر **التثبيت على أي حال**.

## تعدّل التطبيق

الكود كله في ملف واحد:
`app/src/main/java/com/example/counter/MainActivity.java`

عدّله على GitHub مباشرة (زر القلم)، وكل تعديل يشغّل بناء جديد ويطلع APK جديد.
